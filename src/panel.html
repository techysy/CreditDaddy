10Router 连接设置
填 10Router 的访问地址和仪表盘里创建的虚拟 key（sk-…）。key 只保存在 CreditDaddy 守护进程的数据目录（0600），面板里只显示脱敏值。
把本机 Qoder / WorkBuddy 账号推为 10Router 上游连接；zcode 待反代就绪后支持
用量同步（同 10router-sync 插件）
ZCode 只同步官方渠道；经 10Router 中转的 mirasim 调用会跳过，避免重复计数。「10Router 本机」只把实例原生产生的行标记为网关同步。10Router 按行签名去重，重复同步不会产生重复数据。
活动领取
从 ZCode 官方活动接口领取（billing/preview → billing/claim）。领取时通常静默通过人机验证；触发风控时会弹出验证码，按提示完成即可。
ZCode 自动领取计划
开启后按此周期检查活动资格并自动领取（首次检查在开启 2 分钟后开始）。活动包由服务端在每日 0 点左右刷新放出——若运行时段没有覆盖 0 点，会错过当次领取，建议把运行时长设为 0，或让时段跨过 0 点。需要验证码时无法自动通过，卡片上会提示手动领取。
ZCode 体验包接口
开启后，领到的体验包额度变成本机的一个补全接口——10Router 建一个 anthropic-compatible 节点指向本机 /gateway/zcode/v1/messages 即可调用（需要桌面版，隐藏窗口过验证码）。白名单内的机器免密直连：10Router 的 zcode-free 本就是免授权供应商，把 10Router 服务地址的 IP 加白即可；白名单外的请求一律拒绝。本机回环（127.0.0.1）始终放行。
MiniMax 本地接口
开启后，MiniMax 积分与模型能力变成本机的一个原生 Anthropic Messages 补全接口——在 10Router 或 Claude Code 等工具中建一个 anthropic-compatible 节点指向本机 /gateway/minimax/v1/messages 即可调用。支持多账号自动轮转、429 限流自动冷却 5 分钟、凭据失效自动静默刷新。白名单内的机器免密直连；本机回环（127.0.0.1）始终放行。
Trae 本地接口
开启后，Trae SOLO 积分与模型能力（Doubao-Seed / GLM-5.1 / Kimi-K2.6 / DeepSeek-V4 等 12 款模型）变成本机的一个原生 Anthropic Messages 补全接口——在 10Router 或 Claude Code 等工具中建一个 anthropic-compatible 节点指向本机 /gateway/trae/v1/messages 即可调用。支持多账号自动加权轮转、429 限流自动冷却 5 分钟、流式增量与完整思考过程（thinking_delta）。白名单内的机器免密直连；本机回环（127.0.0.1）始终放行。

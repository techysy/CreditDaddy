## Usage

### Adding MiniMax Account
1. Open MiniMax Code desktop client
2. Log in with your account
3. In CreditDaddy panel: Add Account → Import from Local App
4. Token will be extracted from client config (`%APPDATA%\MiniMax Code\storage.json`)

### Daily Sign-in
- MiniMax automatically joins the global check-in scheduler
- Runs every ~2 hours with jitter
- Results show in panel under "领取" column

### Switching Accounts
MiniMax supports account switching if you have multiple accounts imported:
1. Import both accounts into CreditDaddy
2. Click "切换" button in panel
3. Choose target account from dropdown
